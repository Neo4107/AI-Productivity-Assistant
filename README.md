# Work Smarter AI

Build a modern, responsive web application called “AI Workplace Productivity Assistant” for professionals to automate work using AI. Include a dashboard UI with sidebar navigation and clean professional visual system: #2563EB blue, white surfaces, Inter font, card-based layout. Implement these usable sections: (1) Smart Email Generator: purpose and tone inputs, generate an editable email; display the structured prompt used. (2) Meeting Notes Summarizer: paste long notes, produce summary plus action items, editable result, show structured prompt. (3) AI Task Planner: goal input, produce task breakdown with priorities, editable, show structured prompt. (4) AI Research Assistant: question input, provide structured research summary, editable, show structured prompt. (5) Floating AI chatbot interface available across the app. Make it polished, responsive, and intuitive. Add a Responsible AI disclaimer in the footer. Use sensible mock/generative behavior so all interactions can be demonstrated. Do not ask follow-up questions; implement the full product.
